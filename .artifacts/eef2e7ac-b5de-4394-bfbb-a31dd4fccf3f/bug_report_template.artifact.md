# 6. Bug Report Template

> Copy and paste this template into Jira, Trello, or GitHub Issues.

```markdown
**Bug ID:** BUG-[Number]
**Title:** [Short, descriptive summary]
**Module:** [Auth / Menu / Orders / Billing / Inventory / Staff]
**Severity:** [Critical / High / Medium / Low]
**Environment:** [React Web Admin / Flutter App / Django API]

### Description
[What is happening versus what is expected to happen]

### Steps to Reproduce
1. Log in as [Role].
2. Navigate to [URL/Screen].
3. Click on [Button].
4. Observe the result.

### Expected Result
[Document what the system SHOULD do]

### Actual Result
[Document what actually happened, including HTTP status codes or visual errors]

### Attachments
- Error log / Screenshot
```
